# CEDA NERC grants data management tracking

## Purpose
This project supports effective data management for NERC grants, providing a central place to:

- Track dataset status and ownership  
- Monitor data quality, storage, and compliance requirements
- Coordinate tasks related to data ingestion, processing, and archiving
- Improve transparency and collaboration between data centre teams

##  Views

## Quickstart
1. Browse **My projects** to view NERC grants assigned to you
2. Add a new task or dataset entry
3. Assign ownership and relevant metadata  
4. Keep information updated as work progresses
